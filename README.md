# Trappin RP Cloth Builder

Made by Director for Trappin RP.

## [Download the latest version](https://github.com/DirectorBT/trp-cloth-builder/releases/latest/download/TRP-Cloth-Builder.zip)

1. Download the zip and unzip it anywhere (for example the Desktop).
2. Open `TRPClothBuilder.exe`.

Updates: when a new version is out, the tool shows **New version available - Update now** at the top. Your project and clothing are kept.
